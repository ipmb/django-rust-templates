Modes: render times a template that is already compiled; parse includes the compile, through from_string on all four engines so that none of them is served from a cache the others do not have. Two asymmetries are inside these numbers and are named here rather than left for a reader to find: minijinja’s binding exposes no compiled-template handle, so a minijinja render carries one name-table lookup that the other three do not; and the Django-side engines are handed a Context built once per row rather than once per call, which is what the milestone table this supersedes measured — a view that builds one per request pays about the same again on both of them.
