## Review Focus

Five input classes §2 and the runner imply, which no task's happy-path test exercises. Each line's test is added to the owning task.

1. **A green summary line that is not §2's outcome** — `OK (expected failures=1, skipped=6)`, or `OK (skipped=6, unexpected successes=1)`. Both exit 0, both print `OK`, and the first is a *failing* test that the gate would otherwise wave through. This is the sharpest of the five: the exit status is not silent about it, it is wrong about it (measured in `.review/m15-recon.md` §3.3). → Task 1, Step 1's whole-line pin, driven by Step 3's `test_an_expected_failure_is_refused` and `test_a_green_summary_with_another_qualifier_is_refused`.
2. **A transcript with no summary line** — the runner died mid-run (OOM, `SIGINT`, a worker crash). Every regex finds nothing; a gate that treats "no `Ran` line" as "nothing to report" passes on exactly the run that should stop everything. → Task 1, Step 3's `test_a_truncated_transcript_is_refused`.
3. **A summary followed by teardown output** — measured on the real run: eleven `Destroying test database for alias …` lines come *after* `OK (skipped=6)`. A reader that takes the transcript's last line for the verdict refuses every healthy run. → Task 1, Step 3's `test_a_summary_followed_by_teardown_lines_is_still_found`.
4. **A duplicated skip line** — the same test reported twice because a worker retried or output interleaved. A set comparison hides it; the count of lines is what sees it. → Task 1, Step 3's `test_a_duplicated_skip_line_is_refused`.
5. **`.django/` without its `.git`** — someone unpacks a tarball over it, or `fetch_django.sh` is replaced by a manual clone-and-copy. `git status` exits non-zero; the gate must refuse with a named reason, not die on a traceback that reads like a bug in us. → Task 2, Step 3's `test_a_checkout_without_git_is_refused`.
6. **A hand-edited `django.lock`** — the tag says 6.0.9 and the sha says something else. The check must compare both against the checkout, not trust either. → Task 2, Step 3's `test_a_lock_whose_sha_is_not_the_checkouts_is_refused`.
7. **An untracked file planted inside `.django/`** — a `conftest.py` or a `sitecustomize.py` that changes what the suite does without editing a tracked line. `git status --porcelain` shows `??`, so the check must not pass `-uno`. → Task 2, Step 3's `test_an_untracked_file_is_refused`.

"""The acceptance run's own outcome, as a refusal.

`.review/m15-recon.md` §3.1 measured the hole: `check.sh:138-139` reads the
suite's exit status and discards the transcript, so `Ran 1547 tests … OK
(skipped=6)` — §2's central claim — is enforced by nobody. `check_suite_counts.py`
says the same of itself: it checks that a *prose* count names its run, not that
the number is right.

This file drives the gate with **fabricated transcripts**, which is where an
instrument's conditions belong: a literal the gate's parser is exercised on, so
a reworded Django summary fails here and not in production. The subject — the
real set of six — is asserted against `DECLARED_SKIPS` in the gate itself and
tied to §2's prose by `test_the_declared_skips_are_the_ones_section_2_names`.
"""

import unittest

from scripts.assert_suite_outcome import DECLARED_SKIPS, DECLARED_SUMMARY, outcome


def transcript(ran=1547, summary="OK (skipped=6)", skips=(), extra=""):
    """A stand-in for `runtests.py template_tests -v 2`'s output.

    The teardown lines are not decoration. On the real run the summary is
    followed by eleven `Destroying test database for alias …` lines, so the
    verdict is *not* the transcript's last line and a reader that assumes it is
    refuses every healthy run. They are in the stand-in so that assumption
    cannot survive here.
    """
    lines = ["Testing against Django installed in '/x/.django/django' with up to 10 processes"]
    for dotted in skips:
        lines.append(f"{dotted.split('.')[-1]} ({dotted}) ... skipped 'a reason'")
    lines += [extra] if extra else []
    lines += ["", "----------------------------------------------------------------------", ""]
    lines += [f"Ran {ran} tests in 3.5s", "", summary]
    lines += ["Destroying test database for alias 'default' ('default_1.sqlite3')..."]
    return "\n".join(lines)


HEALTHY = tuple(sorted(DECLARED_SKIPS))


class HealthyRunTests(unittest.TestCase):
    def test_the_declared_outcome_is_accepted(self):
        self.assertEqual(outcome(transcript(skips=HEALTHY)).refusals(), [])

    def test_a_refusal_names_the_skip_that_is_not_declared(self):
        report = outcome(
            transcript(skips=HEALTHY + ("template_tests.test_foo.NewTests.test_x",))
        )
        self.assertTrue(
            any("test_foo.NewTests.test_x" in r for r in report.refusals()),
            report.refusals(),
        )

class RefusalTests(unittest.TestCase):
    def test_a_truncated_transcript_is_refused(self):
        """No summary line at all: the runner died. Silence is not a pass."""
        report = outcome("Testing against Django installed in '/x'\n")
        self.assertTrue(report.refusals())

    def test_a_duplicated_skip_line_is_refused(self):
        """A set comparison hides a doubled line; the report must not."""
        doubled = HEALTHY + (HEALTHY[0],)
        report = outcome(transcript(skips=doubled))
        self.assertTrue(any("twice" in r for r in report.refusals()), report.refusals())

    def test_a_swapped_skip_that_keeps_the_count_at_six_is_refused(self):
        """§2:31 — a count of 6 is satisfied by a different 6."""
        swapped = HEALTHY[:-1] + ("template_tests.test_impostor.ImpostorTests.test_x",)
        report = outcome(transcript(skips=swapped))
        self.assertTrue(report.refusals())

    def test_a_failure_is_refused(self):
        report = outcome(transcript(summary="FAILED (failures=1, skipped=6)"))
        self.assertTrue(any("failures=1" in r for r in report.refusals()), report.refusals())

    def test_an_error_is_refused(self):
        report = outcome(transcript(summary="FAILED (errors=1, skipped=6)"))
        self.assertTrue(report.refusals())

    def test_an_expected_failure_is_refused(self):
        """§2:33 — `expected failures=1` exits 0, prints `OK`, and is not zero xfailed.

        Measured in `.review/m15-recon.md` §3.3: a single
        `@unittest.expectedFailure` on a failing test yields
        `OK (expected failures=1)` with exit status 0. The exit status is not
        silent about this clause, it answers wrongly, which is why the gate
        compares the summary *line* instead of trusting `OK`.
        """
        report = outcome(transcript(summary="OK (expected failures=1, skipped=6)"))
        self.assertTrue(any("expected failures" in r for r in report.refusals()), report.refusals())

    def test_a_green_summary_with_another_qualifier_is_refused(self):
        """The same mechanism, one qualifier over: `OK` is not the whole claim."""
        report = outcome(transcript(summary="OK (skipped=6, unexpected successes=1)"))
        self.assertTrue(
            any(DECLARED_SUMMARY in r for r in report.refusals()), report.refusals()
        )

    def test_a_summary_followed_by_teardown_lines_is_still_found(self):
        """The verdict is not the last line — `runtests.py` prints eleven teardown
        lines after it on the real run, so a `lines[-1]` reader refuses a healthy
        transcript."""
        report = outcome(transcript(skips=HEALTHY))
        self.assertEqual(report.summary, DECLARED_SUMMARY)
        self.assertEqual(report.refusals(), [])

    def test_a_changed_run_count_is_refused(self):
        report = outcome(transcript(ran=1546, skips=HEALTHY))
        self.assertTrue(any("1546" in r for r in report.refusals()), report.refusals())

    def test_a_skip_on_a_docstringed_test_is_seen(self):
        """`-v 2` splits a documented test across two lines.

        Measured on the transcript `scripts/run_django_suite.sh -v 2
        template_tests` writes: an undocumented test prints
        `name (dotted) ... skipped 'reason'` on one line, while a documented one
        prints `name (dotted)` and then `Docstring first line. ... skipped
        'reason'` on the next. A parser that requires the `... skipped` on the
        name's own line silently misses every documented skip — and the run that
        would expose it is the regression this gate exists for.
        """
        two_line = (
            "Testing against Django installed in '/x'\n"
            "test_x (template_tests.test_doc.DocTests.test_x)\n"
            "Some docstring. ... skipped 'jinja2'\n"
            "\nRan 1547 tests in 3.5s\n\nOK (skipped=1)\n"
        )
        self.assertEqual(outcome(two_line).skips, ["template_tests.test_doc.DocTests.test_x"])

```python
#!/usr/bin/env python3
"""Refuse unless the acceptance run's transcript is §2's outcome.

§2:31-34 and §2:66, read against the tree in `.review/m15-recon.md` §3.1: the
count, the zero-failure clause and "any *new* skip appearing later is a
regression" are carried by prose. `check.sh:138-139` runs
`scripts/run_django_suite.sh template_tests` and reads its exit status; the
transcript is printed and dropped.

The count is the weaker half of §2's own clause, and the recon probed why:
`template_tests/syntax_tests/test_numpy.py:13`'s `@skipIf(numpy is False, …)`
guards two tests §2:64-65 requires to run, and a skipped test is still
collected — so losing Numpy prints `Ran 1547 tests … OK (skipped=8)`, §2's exact
run count, with two tests silently not running. So the gate pins the summary
**line whole** and the six skips **by identity**, and refuses on each of: a run
count that is not 1547, a summary that is not `OK (skipped=6)`, any skip outside
`DECLARED_SKIPS`, and any of the six that did not skip.

Usage:
    python scripts/assert_suite_outcome.py <transcript>
"""

from __future__ import annotations

import re
import sys
from pathlib import Path

# §2:31-33 in two constants. The summary is pinned *whole* rather than taken
# apart, because every clause §2 states about the run's outcome moves that one
# line and `OK (…)` with any other qualifier is a different string: a failure or
# an error turns `OK` into `FAILED`, an `expectedFailure` appends
# `expected failures=N` while leaving `OK` (measured, `.review/m15-recon.md`
# §3.3), a changed skip total changes the number. Dissecting the line recovers
# those facts at the cost of a parser that can be wrong about them; comparing it
# cannot.
#
# It is a literal because this is an *instrument* condition — Django's output
# format, which §2 describes in prose ("1547 tests run; 1541 pass; exactly 6
# skip") and never spells out. The *subject* — which six — is `DECLARED_SKIPS`,
# tied to §2's frame by `test_the_declared_skips_are_the_ones_section_2_names`.
DECLARED_RAN = 1547
DECLARED_SUMMARY = "OK (skipped=6)"

# §2:35-45 enumerates these six; §2:64-65 puts Numpy's two back in scope. The
# literal is here rather than parsed out of §2 because §2 composes the names —
# a class plus parenthesised methods, and a bare `test_using` belonging to two
# classes named later in the sentence — and a reader that reassembles them
# wrongly answers with a *wrong set* rather than an error.
# `tests/test_suite_outcome.py` holds the tie to the frame and every refusal arm.
DECLARED_SKIPS = frozenset(
    {
        "template_tests.test_autoreloader.Jinja2TemplateReloadTests.test_get_template_directories",
        "template_tests.test_autoreloader.Jinja2TemplateReloadTests.test_reset_all_loaders",
        "template_tests.test_autoreloader.Jinja2TemplateReloadTests.test_watch_for_template_changes",
        "template_tests.test_loaders.FileSystemLoaderTests.test_case_sensitivity",
        "template_tests.test_response.SimpleTemplateResponseTest.test_using",
        "template_tests.test_response.TemplateResponseTest.test_using",
    }
)

# The `Ran` line cannot be pinned whole the way the summary is: `runtests.py`
# prints its elapsed time, which is the instrument's fact and not ours (3.603s
# and 3.611s across two measured runs). The count and the prefix are ours.
RAN_RE = re.compile(r"^Ran (\d+) tests? in ", re.M)
SUMMARY_RE = re.compile(r"^(OK|FAILED)(?: \(([^)]*)\))?[ \t]*$", re.M)
COUNT_RE = re.compile(r"(?P<key>[a-z][a-z ]*?)=(?P<value>\d+)")
# A test's first line at verbosity 2. The `... skipped` that belongs to it is on
# the same line when the test has no docstring and on the next one when it has
# — measured on the real transcript, where the six declared skips are
# undocumented and Numpy's two are not. So the skip scan looks back for the
# nearest label rather than requiring both on one line.
LABEL_RE = re.compile(r"^(?P<label>\S.*?) \((?P<dotted>[\w.]+)\)", re.M)
SKIP_TOKEN = "... skipped "


class Report:
    def __init__(self, ran, summary, counts, skips, lines):
        self.ran = ran
        self.summary = summary  # the summary line verbatim, or None
        self.counts = counts  # parsed out of it, for this file's own check below
        self.skips = skips  # list of dotted names, in transcript order
        self.lines = lines

    def refusals(self) -> list[str]:
        out = []
        if self.summary is None:
            return [
                "the transcript has no `OK`/`FAILED` summary line — the run did "
                "not finish, and an unfinished run is not a pass"
            ]
        if self.summary != DECLARED_SUMMARY:
            out.append(
                f"the run ended `{self.summary}` and §2:31-33 pins "
                f"`{DECLARED_SUMMARY}`"
            )
        if self.ran is None:
            out.append("the transcript has no `Ran N tests` line")
        elif self.ran != DECLARED_RAN:
            out.append(f"Ran {self.ran} tests, and §2:31 declares {DECLARED_RAN}")
        seen = set()
        for dotted in self.skips:
            if dotted in seen:
                out.append(f"{dotted} is reported twice — the transcript is not one run")
            seen.add(dotted)
        found = set(self.skips)
        for dotted in sorted(found - DECLARED_SKIPS):
            out.append(f"{dotted} skipped and §2:35-45 does not declare it")
        for dotted in sorted(DECLARED_SKIPS - found):
            out.append(f"§2:35-45 declares {dotted} and the run did not skip it")
        # The one place a *parsed* number is still read, and it is a claim about
        # this file rather than about §2: the summary saying `skipped=6` and the
        # scan finding six skips are the same fact only if the scan attributed
        # every one. A skip line whose label the look-back misses is dropped
        # silently, which would leave the identity checks above green on a
        # transcript that reported seven.
        declared = self.counts.get("skipped")
        if declared is not None and declared != len(self.skips):
            out.append(
                f"the summary says skipped={declared} and {len(self.skips)} skip "
                f"line(s) were attributed to a test"
            )
        return out


def _last(pattern: "re.Pattern[str]", text: str) -> "re.Match[str] | None":
    """The **last** match, which is not the last line.

    Two measurements say so. At verbosity 2 a test's docstring is printed at
    column 0 too, so a docstring whose first line reads `OK` must not be
    mistaken for the run's verdict; and the real transcript prints eleven
    `Destroying test database for alias …` lines *after* its summary, so a
    reader that takes `lines[-1]` refuses every healthy run.
    """
    matches = list(pattern.finditer(text))
    return matches[-1] if matches else None


def outcome(transcript: str) -> Report:
    """Parse one acceptance transcript. Pure, so a test can drive a fabricated one."""
    ran_match = _last(RAN_RE, transcript)
    summary_match = _last(SUMMARY_RE, transcript)
    counts: dict[str, int] = {}
    if summary_match and summary_match.group(2):
        counts = {
            m.group("key").strip(): int(m.group("value"))
            for m in COUNT_RE.finditer(summary_match.group(2))
        }
    # Each skip belongs to the nearest label at or before it: undocumented tests
    # print `name (dotted) ... skipped 'reason'` on one line, documented ones
    # print the label and then the docstring's first line carrying the
    # `... skipped`. Measured on the real transcript; pinned by
    # `test_a_skip_on_a_docstringed_test_is_seen`.
    labels = list(LABEL_RE.finditer(transcript))
    skips: list[str] = []
    cursor = 0
    while (at := transcript.find(SKIP_TOKEN, cursor)) != -1:
        cursor = at + 1
        owner = None
        for label in labels:
            if label.end() > at:
                break
            owner = label
        if owner is not None:
            skips.append(owner.group("dotted"))
    return Report(
        ran=int(ran_match.group(1)) if ran_match else None,
        summary=summary_match.group(0).strip() if summary_match else None,
        counts=counts,
        skips=skips,
        lines=transcript.splitlines(),
    )


def main(argv: list[str]) -> int:
    if len(argv) != 2:
        sys.stderr.write("usage: assert_suite_outcome.py <transcript>\n")
        return 2
    report = outcome(Path(argv[1]).read_text(encoding="utf-8", errors="replace"))
    refusals = report.refusals()
    if refusals:
        for line in report.lines:
            print(line)
        sys.stderr.write("\n" + "\n".join(refusals) + "\n")
        sys.stderr.write(
            "refusing: §2's acceptance criterion is 1547 run, zero failures and "
            "errors, and exactly the six skips it enumerates — by identity.\n"
        )
        return 1
    print(
        f"{report.summary} after {report.ran} tests, and the six declared skips "
        f"by identity (scripts/run_django_suite.sh)"
    )
    return 0


if __name__ == "__main__":
    raise SystemExit(main(sys.argv))
```

```python
#!/usr/bin/env python3
"""Refuse unless `.django/` is the checkout `django.lock` pins and is unmodified.

§2:33-34: "zero edited tests. Django's checkout is never modified; the suite is
run unmodified." Read against the tree in `.review/m15-recon.md` §3.2: nothing
asserted it. This is the clause where a deliberate, well-intentioned edit — the
usual way one "fixes" a failing Django test — produces a fully green, fully
meaningless gate, which is why it is checked before the suite rather than after.

Both halves are checked because either alone is satisfiable while the other is
false: a clean tree at the wrong tag is a different Django, and the right tag
with a patched file is not stock Django.

This runs for every invocation of `run_django_suite.sh`, shimmed or not: the
clause is about the suite, not about our engine.
"""

from __future__ import annotations

import subprocess
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
CHECKOUT = ROOT / ".django"
LOCK = ROOT / "django.lock"


def lock_values(text: str) -> dict[str, str]:
    """`django.lock`'s `key=value` lines. Pure, so a test can hand it a fake."""
    values = {}
    for line in text.splitlines():
        if "=" in line:
            key, _, value = line.partition("=")
            values[key.strip()] = value.strip()
    return values


def dirt(porcelain: str) -> list[str]:
    """`git status --porcelain`'s lines, verbatim.

    Deliberately *not* `-uno`: an untracked file planted in the checkout changes
    what the suite does just as surely as an edited line, and `??` is how it
    shows. A trailing newline is not an entry.
    """
    return [line for line in porcelain.splitlines() if line.strip()]


def refusals(lock: dict[str, str], head: str, porcelain: str) -> list[str]:
    """Every reason this checkout is not the pinned, unmodified one."""
    out = []
    if not lock:
        out.append("django.lock is empty or missing its k=v lines")
    if lock.get("sha") != head:
        out.append(
            f"the checkout is at {head} and django.lock records {lock.get('sha')!r}"
        )
    for line in dirt(porcelain):
        out.append(f"the checkout is modified: {line}")
    return out


def git_dir_problem(git_dir: Path) -> str | None:
    """The one check that runs before `git` can be trusted to answer.

    A checkout copied from a tarball, or a `fetch_django.sh` replaced by a manual
    clone-and-copy, has no `.git` — and then `git status` exits non-zero and says
    nothing about §2. Naming it here keeps the refusal readable instead of
    surfacing as an exception from a script whose job is to be boring.
    """
    if not git_dir.exists():
        return (
            f"there is no .git at {git_dir}; the checkout cannot be checked, and "
            "§2:33-34 is the clause a green run cannot see"
        )
    return None


def inspect_checkout(checkout: Path = CHECKOUT, git=subprocess.run) -> list[str]:
    """`refusals` against a live checkout. Both arguments are for the controls."""
    problem = git_dir_problem(checkout / ".git")
    if problem:
        return [problem]

    def run(*args: str) -> str:
        return git(
            ["git", "-C", str(checkout), *args],
            capture_output=True,
            text=True,
            check=True,
        ).stdout

    try:
        head = run("rev-parse", "HEAD").strip()
        porcelain = run("status", "--porcelain")
    except (subprocess.CalledProcessError, FileNotFoundError) as exc:
        return [f"git could not read the checkout: {exc}"]
    lock = lock_values(LOCK.read_text(encoding="utf-8")) if LOCK.exists() else {}
    return refusals(lock, head, porcelain)


def main() -> int:
    problems = inspect_checkout()
    if problems:
        for line in problems:
            sys.stderr.write(line + "\n")
        sys.stderr.write(
            "refusing to run the acceptance suite: §2:33-34 pins the checkout, "
            "and it is the one thing a green run cannot tell you about.\n"
        )
        return 1
    sys.stderr.write("checkout pinned and unmodified\n")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
