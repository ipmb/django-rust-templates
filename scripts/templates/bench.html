How to read these results

Full-page, filter, and tag timings report the best of {{ args.repeats }} samples, using the same calibrated call count for each engine. Template loaders are cached and contexts are created outside the timed loop. This measures template work, rather than complete HTTP requests.

Results depend on the template, inputs, Python version, and machine. Small differences may be timing noise. Bakerydemo uses medians from its own recorded run and is reported separately.
